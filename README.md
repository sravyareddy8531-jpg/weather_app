# 🌦️ Weather App

A simple weather web application built using HTML, CSS, and JavaScript that shows real-time weather information for any city using OpenWeather API.

---

## 🚀 Features

- Search weather by city name  
- Real-time temperature display  
- Humidity details  
- Wind speed information  
- Weather condition icons  
- Responsive design for mobile & desktop  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript  
- OpenWeather API  

---

Open index.html directly OR use VS Code Live Server
